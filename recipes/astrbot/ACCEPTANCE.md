# 验收

以下是未来重建的验收条件，不表示已执行。所有项目应记录版本、环境、命令、结果与未覆盖范围；涉及外部平台时分别记录模拟与真实平台结果。

- **配方完整性**：离线校验、递归依赖检查、临时打包与构建提示词渲染通过；包只包含 UTF-8 Markdown。逐一审查基线 OpenAPI、旧接口、插件接口、平台特性、数据迁移与视觉证据后才可宣称行为清单完整。
- **安装与持久化**：新目录 `init`、配置和 `run` 成功；重启后配置及对话仍可读取；无效配置给出明确错误，重复初始化不覆盖用户数据。正常和异常退出均释放资源。
- **身份与权限**：首次设置、登录、登出、失效令牌和权限不足均正确；API key 的 scope 对已启用路由真实生效；不能读取未授权用户、会话或知识库数据。错误和日志不暴露密钥。
- **消息链路**：各官方平台至少通过模拟适配器接收并回复文本及该平台声明支持的媒体；实网分别验证授权的账号。群、私聊、多个用户和不同平台的会话不串话；未唤醒与无权限消息遵守配置。
- **模型与工具**：验证流式/非流式、失败、超时、工具请求、多个 tool_call 的唯一 ID 与完整回执、插件修改上下文和重启后历史。工具图片不得插入 assistant 的 tool_calls 和对应 tool 回执之间；不支持图片的模型明确降级或拒绝，不能污染后续会话。
- **负载和取消**：并发同会话请求时，队列长度与等待时间受配置限制；溢出和超时有可观察结果；停止后排队任务不启动新的模型请求，重复停止不会重复计数或重复发送。不同会话不能因一方阻塞无限等待。
- **技能与插件**：安装依赖部分已存在的插件仍处理缺失依赖；安装失败可诊断，启停后事件/命令和已启用的工具符合配置。沙盒只同步当前允许的技能，关闭或未勾选的技能不上载；未声明的隔离能力不能当成安全保证。
- **知识库**：上传、解析、索引、检索、删除、重启恢复及拒绝未授权请求；反复上传后连接和线程有界，错误时资源释放。
- **WebUI**：首次设置、登录、配置、聊天、插件市场和知识库完整走通；检查加载、空、失败、窄屏、键盘及四种已列语言。与基线的实际页面逐项对照并记录差异；当前没有实机截图或视觉基线。
- **任务与备份**：计划任务按配置触发并投递到指定会话；正在运行时用户再次发言仍能获得一致历史。备份导出并在独立环境恢复，校验配置和会话，而不仅仅检查文件存在。
- **性能**：先采集基线与测试环境，再用相同负载比较；无数字门槛时报告实测而非声称达标。
